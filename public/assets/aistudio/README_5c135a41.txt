RICHSON INTERACTIVE AVATAR — NETLIFY DEPLOYMENT

1. Extract this ZIP file.
2. Open Netlify and choose Add new site > Deploy manually.
3. Drag the extracted folder (the one containing index.html) into the deploy area.
4. Open the generated Netlify URL and move your mouse around the portrait.

This is a standalone homepage prototype. No build command or backend is required.

Interaction:
- Left/right/up/down cursor positions switch between the five supplied portrait expressions.
- The portrait also tilts slightly in 3D using CSS perspective.
- On touch screens, tap different areas of the portrait to change its expression.

Note:
The five supplied photographs are used as expression states. This is a convincing interactive prototype, not a fully rigged 3D facial model. For independent eye movement, blinking, mouth animation and continuous 3D head rotation, a separately rigged 3D avatar would be needed.
